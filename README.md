# Arduino-Projects
## Traffic Light Simulator
### Components
- 3 LED lights
- 1x Bread Board
- Arduino R4 Wifi
- 1 Push Button
- 4 1k ohm Resistors
### How it Works
- While the system waits for the button to be pressed, the red lights will stay on to indicate no cars should be crossing the intersection.  Once button is pressed (car has triggered the sensor) the system will start the light cycle.
- A Serial connection is active to allow the board to notify the user computer when button is pressed and when it's turning certain led's on.
